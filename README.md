📧 Smart Email Validator
A Python-based Email Validator with a modern GUI that verifies email addresses using multiple validation techniques including format checking, DNS lookup, and disposable email detection.

🚀 Features
- ✅ Email Format Validation  
- 🌐 DNS MX Record Check  
- 🚫 Disposable Email Detection  
- 📂 Bulk Email Validation (CSV Upload)  
- 📊 Data Visualization (Graph Statistics)  
- 💾 Download Results as CSV  
- 🎨 Clean Dark-Themed GUI  

🖥️ Tech Stack
- Python  
- Tkinter (GUI)  
- dnspython (DNS lookup)  
- matplotlib (data visualization)  
- CSV (bulk processing)
